# Checklist 11 — Risk Management & Fallbacks

Named risks are managed risks. Unnamed risks become pivots.
Rate each: PRESENT / PARTIAL / MISSING

- [ ] **11.1 Risk Register**
  Table with: risk name, likelihood (H/M/L), impact (H/M/L), mitigation strategy.
  Not buried in prose — a scannable table. Minimum 5 entries for non-trivial projects.

- [ ] **11.2 Plan B / Fallback Strategies**
  For the highest-risk decisions: an explicit alternative approach if the
  primary fails. "Plan B: if X doesn't work, we do Y instead."

- [ ] **11.3 Ambition Calibration**
  For ambitious plans: explicit statement of what is aspirational vs. committed.
  Prevents "but the plan said..." pivot pressure when aspirational items slip.

- [ ] **11.4 Known Unknowns**
  List of things that are not known at plan time, with a resolution strategy for each.
  Converts implicit assumptions into explicit, tracked questions.

- [ ] **11.5 Incident Class Prevention**
  For improvement plans: name the real failure or incident that prompted this plan.
  Prevents solving the wrong problem ("we're fixing symptoms, not the root cause").
